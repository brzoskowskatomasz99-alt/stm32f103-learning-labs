# STM32F103 OLED 小恐龙游戏

基于 STM32F103C8T6、SSD1306 OLED、单按键和 LED3 的小恐龙游戏实验。目标是在已经跑通的 I2C/OLED 工程上完成一个可交互、可计分、碰撞后可重新开始的裸机小游戏。

## 硬件与引脚

| 功能 | STM32 引脚 | 配置与作用 |
| --- | --- | --- |
| OLED SCL | PB6 | I2C1_SCL，100 kHz |
| OLED SDA | PB7 | I2C1_SDA |
| SW1 | PB12 | 上拉输入，按下为低电平，用于跳跃和重新开始 |
| LED3 | PB15 | 推挽输出，碰撞后快速闪烁 |

OLED 驱动使用地址常量 `0x78`。工程仍保留蜂鸣器等早期模块和代码，但本实验没有启用蜂鸣器反馈。

## 工程入口与关键模块

- CubeMX 配置：`Template.ioc`
- Keil 工程：`MDK-ARM/Template.uvprojx`
- 启动入口：`Core/Src/main.c`
- 游戏逻辑：`MDK-ARM/UserCode/app_main.c`
- OLED 驱动：`Core/Src/oled.c`、`Core/Inc/oled.h`
- GPIO 配置：`Core/Src/gpio.c`、`Core/Inc/main.h`

启动流程：

```text
HAL_Init
  -> SystemClock_Config
  -> MX_GPIO_Init
  -> MX_I2C1_Init
  -> app_main
```

## 实现流程

1. OLED 驱动维护 128×64 单色帧缓冲，提供画点、矩形、位图和整屏刷新。
2. 主循环使用 `HAL_GetTick()` 每 100 ms 更新游戏帧，不使用阻塞式跳跃延时。
3. SW1 使用 20 ms 消抖；游戏中按下触发跳跃，碰撞停止后再次按下可重新开始。
4. 仙人掌从右向左移动，离开屏幕后复位；恐龙与仙人掌使用收窄后的矩形碰撞区域。
5. 每成功越过一个仙人掌，当前分数加 1；最高分只在本次上电期间保存在 RAM，最大显示为 999。
6. 碰撞后显示结束标记，LED3 每 80 ms 翻转一次，约闪烁 5 次；重新开始会立即关闭残余闪烁。

## 打开、构建与下载

1. 使用 Keil MDK 打开 `MDK-ARM/Template.uvprojx`。
2. 按 `F7` 编译工程。
3. 连接 STM32F103C8T6 开发板，按 `F8` 下载并运行。
4. OLED 左上角 `S000` 表示当前分数，右上角 `H000` 表示本次上电最高分。

## 已知限制与待改进

- 当前构建的 1 条警告为 `MX_GPIO_Init` 隐式声明；后续可在 `Core/Src/main.c` 中恢复 `#include "gpio.h"` 后重新构建验证。本快照保留已由用户验证的当前源码，没有在归档时改写。
- 最高分没有写入 Flash 或 EEPROM，开发板断电或复位后会归零。
- 本实验按用户选择不使用蜂鸣器。
- 生成的 AXF、HEX、对象文件、构建日志、个人 Keil 配置和 J-Link 日志未纳入快照。
