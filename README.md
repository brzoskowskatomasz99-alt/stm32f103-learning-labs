### 状态说明

- **用户确认做过**：记录学习经历，不等同于当前重新编译或真机验证。
- **已归档**：仓库中存在可检查的源码与工程配置。
- **未保存独立快照**：不要求重新做；以后找到备份或需要复习时，再整理成独立实验目录。

## 使用方法

1. 进入需要学习或复现的实验目录。
2. 使用 STM32CubeMX 打开该目录下的 `.ioc` 文件。
3. 使用 Keil MDK 打开 `MDK-ARM` 下的 `.uvprojx` 工程。
4. 编译、下载并在开发板上验证实验现象。

## 添加新实验

新实验使用连续编号和简短英文名称，例如：

```text
02-gpio-led/
03-timer-pwm/
04-uart/
```

每个实验应保留独立工程，并在自己的 `README.md` 中记录目标、接线、关键代码和验证状态。
